# UI library

## Overview

`@bazak/ui` exposes `Button` at `/components/button`, `Card` at `/components/card`, `cn` at `/lib/utils`, and theme and base styles at `/globals.css`.

## Subdirectories & Boundaries

- [src](./src/README.md) · Presentation primitives, utilities, and styling.

## Verification

Run `pnpm --filter @bazak/ui typecheck` from the workspace root.
